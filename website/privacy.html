PRIVACY

You decide where speech goes and where text stays.

FlowSpeech supports local recognition and keeps file export off until you explicitly enable it.

⌂

Local recognition

Local Whisper can process speech without sending audio to cloud ASR.

◉

Explicit cloud choice

Cloud ASR and text cleanup are separate settings. You choose the provider.

▣

Your files

Markdown export writes only to the folder you selected.

A local note can still be synchronized by a service you chose.

If that folder is synchronized by another tool, that tool follows its own rules. FlowSpeech only writes locally and does not change external sync settings.
